# Roadmap Para Transformar Em SaaS

## Fase 0: MVP De Apresentação

Status: concluído.

Entregas:

- Protótipo navegável.
- Perfis simulados.
- Fluxo visual completo.
- Publicação no GitHub.
- Documentação do piloto.

## Fase 1: Piloto Real

Objetivo: operar com uma marcenaria real e validar o processo.

Entregas:

- Banco Supabase configurado.
- Auth configurado.
- Dados reais do primeiro cliente.
- Frontend conectado ao backend.
- Upload real de fotos e arquivos.
- Deploy público.
- Feedback semanal.

Critério de saída:

- Pelo menos 3 projetos reais acompanhados.
- Pelo menos 5 usuários usando.
- Lista fechada de ajustes para produção.

## Fase 2: Produto Operacional

Objetivo: deixar o sistema robusto para uso recorrente.

Entregas:

- Multiempresa.
- Permissões com Row Level Security revisadas.
- Auditoria de ações.
- Notificações.
- Relatórios operacionais.
- Backup/exportação.
- Tratamento de erros.
- Mobile polish.

Critério de saída:

- Primeiro cliente operando sem acompanhamento diário.

## Fase 3: SaaS Comercial

Objetivo: vender para outras marcenarias.

Entregas:

- Landing page.
- Onboarding self-service.
- Planos e cobrança.
- Área administrativa interna.
- Templates de processo.
- Documentação de suporte.
- Termos de uso e privacidade.

Critério de saída:

- Novas marcenarias conseguem entrar sem implantação manual pesada.

## Decisões De Produto Em Aberto

- Arquivos no Supabase Storage ou Google Drive?
- Login por senha, magic link ou Google OAuth?
- Usuário pode ter múltiplos perfis?
- Compras terão controle financeiro completo?
- Montador precisa operar offline?
- Notificações serão por WhatsApp, e-mail ou ambos?
- O SaaS terá assinatura mensal por usuário, por empresa ou por volume de projetos?
